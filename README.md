# Croma Product Inventory Analysis

## About the Project

This project is based on Croma product inventory data.

I used SQL to analyze product prices and manufacturer information and
understand different pricing patterns in the inventory.

## Tools & Technologies

- SQL
- DBeaver

## Dataset

The project contains two tables:

- `product_inventory`
- `manufacturers`

The dataset includes information about products, prices, and manufacturers.

## Analysis

In this project, I analyzed:

- Product-wise prices
- Average product prices
- Total product costs
- Price ranges
- Cheapest products
- Most expensive products
- Manufacturer-wise average prices
- Product and manufacturer information
- Discount prices
